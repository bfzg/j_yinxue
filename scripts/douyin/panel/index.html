首次上线四步（函数和路径都带 jy- 前缀：这个服务空间和另一个项目共用，/upload 已被占）
  1. 自检：.venv/bin/python run.py cloud check（语法 / 令牌 / 哪个函数版本落后）
  2. HBuilderX 里右键 cloudfunctions/function-jy-content、function-jy-upload 这两个目录 →「上传部署」，别去找 zip
  3. 给两个函数开 URL 化，分别绑 /jy-content、/jy-upload，请求方式都要允许 POST
  4. 云存储把 jiugeyinxue/ 目录设为公共读，再点下面的「测试连接」

小程序后台还要加合法域名：request 加 dev-hz.cloudbasefunction.cn，request + downloadFile 都加 normal.cloudstatic.cn。

四个地址在 uniCloud 控制台「支付宝云 · 服务空间」里能查到：dev-hz 是云函数 URL 化域名，normal.cloudstatic.cn 是内置云存储下载域名，永久直链靠它，所以必须把 jiugeyinxue/ 目录设为公共读，否则只能拿到几小时的临时签名地址。

令牌走 x-admin-token 头，本地存 scripts/douyin/unicloud.key（已 gitignore），云端存在云函数环境变量 ADMIN_TOKEN 或 secret.js，两边必须一致。

上架到云端

数量上限给 0 表示不限。上架 = 音频 mp3 + 正文 txt 传云存储 → 取回永久直链写回本地库 → 账号/栏目/分集元数据推云数据库 → 线上 dataVersion +1（小程序按它决定要不要重新拉数据）。单请求上限 28MB，超长音频会自动改走分片直传。

「只重推正文」是给改排版用的：只动已上线的条目，正文几 KB 一篇，音频一个字节都不碰。重推后地址带新的内容指纹（?v=），CDN 那份旧缓存自然作废，不用去控制台刷预热。勾「试跑」只看清单。

封面是一个合集一张：取合集的第一张图（合集自己没封面就退到集序最靠前那一集的封面），抓下来存成 jiugeyinxue/{账号}/{合集}/cover.jpg，线上只落云存储永久直链，不再依赖抖音那条带签名的链接。上架流程会自动带上这一步，单独改了合集归属或想换封面时才需要手动点。

下架：在「作品队列」勾选单集，或在上方选好栏目/账号后什么都不勾直接点，就是整栏下架。下架只把线上分集置为不可见，并且会记住：之后再点上架、同步元数据都不会把它们重新点亮，想恢复就点「重新上架」。勾选「连文件一起删」才会真的删云存储；「撤回本地」只清本地的云端地址，下次上架会重新上传。
